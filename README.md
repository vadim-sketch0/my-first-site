# my-first-site

Персональна сторінка здобувача освіти — лабораторна робота № 1 з дисципліни «Веб-програмування».

**Автор:** Якимчук Вадим Сергійович, група КІІ 61б, МЕГУ ім. акад. С. Дем’янчука.

## Структура

```
my-first-site/
├── index.html      — HTML-документ
├── favicon.svg     — піктограма сайту
├── .editorconfig   — налаштування редактора
├── .gitignore      — файли, виключені з репозиторію
├── README.md       — опис проєкту
├── css/main.css    — стилі
├── img/            — зображення
└── assets/         — інші ресурси
```

## Запуск

Відкрити `index.html` у браузері або запустити через розширення Live Server у VS Code.
